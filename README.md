# ZG-Desktop

ZG-Desktop 是「張國官網」的桌面應用程式版本，提供穩定的線上瀏覽體驗，並在網路不穩或中斷時自動切換為離線內容，確保網站依然可以正常開啟與使用。

本專案以「好用、穩定、免思考」為設計目標，適合一般使用者直接下載安裝，也方便開發者進行後續維護與擴充。

---

## 功能特色

* **線上 / 離線自動切換**
  預設優先載入線上網站，若載入失敗或逾時，會自動改用本機的離線版本。

* **離線快取更新**
  在應用程式內即可一鍵更新離線內容，確保資料保持最新。

* **清楚的狀態提示**
  介面會顯示目前是否為「載入中」或「離線模式」，使用狀態一目了然。

* **簡單直覺的操作**
  提供返回首頁功能，快速切換不同站台。

---

## 內建站台

ZG-Desktop 預設內建多個張師社會主義民主共和國相關站台，例如：

* 官方網站
* 相關子站與應用服務
* 線上聊天與互動頁面

實際站台清單可依需求進行調整與擴充。

---

## 使用方式

1. 啟動 ZG-Desktop。
2. 在首頁選擇欲開啟的站台。
3. 若網路正常，會直接顯示線上版本。
4. 若網路異常，系統會自動切換為離線內容。
5. 需要更新離線資料時，點擊「刷新離線快取」即可。

整個流程不需要額外設定，開箱即用。

## 開發與建置

### 環境需求

* Node.js 18 以上（建議使用 LTS）
* npm

### 安裝相依套件

```bash
npm install
```

### 開發模式

```bash
npm start
```

### 建置與打包

```bash
npm run make
```

### 程式碼檢查

```bash
npm run lint
```

> 上述 npm pipeline 為專案主要的開發與發佈流程，適合日常開發與正式發行使用。

---

## 客製化站台（進階）

ZG-Desktop 支援自行新增或修改站台來源，用於對應不同的網站與離線內容。
此部分屬於進階用法，適合有開發需求的使用者。
